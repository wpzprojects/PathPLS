9

Agregar el nivel de tensión del proyecto

Terrain›Feature Code Data›Edit…›Add

Agregar no solamente el nivel de tensión del proyecto sino también el nivel de tensión de las redes existentes que tengan interferencia con el proyecto

Terrain›Feature Code Data›Edit…›Continue to Feature Code Data Edit Dialog

En este paso se crean o editan los códigos característicos, igualmente se configuran los símbolos de visualización, las propiedades de cada código y las distancias verticales y horizontales a respetar con cada nivel de tensión

Terrain›Clearance Line…

Se selecciona el nivel de tensión del proyecto y el código del terreno (normalmente el 200), se puede colocar una distancia adicional de seguridad en el campo "Vertical buffer" (útil para red compacta donde puede ir la distancia entre el portante y la fase inferior)

Terrain›Terrain Widths…

"Width of Profile View" define el ancho total considerado para dibujar los elementos en el perfil, se puede establecer el ancho de la servidumbre o aumentarlo si se desea incluir más información. "Profile View Ground" determina el ancho considerado para trazar la línea de terreno en el perfil. Puede configurarse en 1 metro (aunque este valor puede ser mayor en caso de que los puntos de terreno no sean lo suficientemente densos)

Terrain›Edit›Merge Points for External File›Merge Points from LAS/LAZ Files…

Se debe asignar a cada clase de punto del estándar ASPRS el código característico (del .FEA) que le corresponda, los elementos como ruido y otros que no sean necesarios no se importan. Esta configuración se puede guardar y luego cargar en cualquier proyecto para facilitar la asignación.

Terrain›Edit›Merge Points for External File›Merge Points from Internet...

Se selecciona el código carácteristico donde se guardarán los puntos a descargar (se recomienda 201 detalle de nivel) y se selecciona la opción "current plan view extents". Cargar antes un poligono en kmz con la localización del proyecto para que los puntos descargados queden en la zona correcta (Terrain > Edit > Merge Points for External File > Merge Points from KML/KMZ Files…)

Terrain›TIN›Create Interpolated Points

Con esta acción se refina el perfil sobre el alineamiento. En "Offsets where interpolation is desired (space delimited)" ingresar la configuración preferida (ej: 0 1 2 3 -1 -2 -3) esto depende de la densidad de los puntos del terreno y del ancho de servidumbre del proyecto. Esta opción Define las distancias laterales [offsets] desde el eje del alineamiento [centro de la línea de transmisión] donde el modelo TIN debe interpolar puntos de elevación para crear puntos de terreno)

Terrain›TIN›Add point XY

Criterios de diseño

El archivo .cri. Aquí la normativa se vuelve números.

15 pasos
Criteria›Weather…
Criteria›Creep-Stretch…
  • Con esta acción se asignan los casos climáticos utilizados para calcular el alargamiento permanente de los conductores debido al efecto de creep (fluencia) a largo plazo y a cargas extremas a corto plazo
  • Creep: Deformación lenta y permanente del conductor bajo tensión sostenida en el tiempo (ej: temp máxima)
  • Load: Estiramiento permanente por cargas extremas de corta duración (ej: viento, temp mínima o hielo)
Criteria›Bimetallic Conductor Model…

Se deja la opción 1 si se quiere ser más conservador y 2 si se quieren vanos mas largos con Temp Max

Criteria›Cable Tensions…
Criteria›Automatic Sagging…
Criteria›Weight Span Model…

Se selecciona la opción "Exact method (always correct)"

Criteria›Weight Spans (method 1)…

Se cargan los criterios (casos climaticos y condición del conductor) para el cálculo de vano peso

Criteria›Survey Point Clearance and Danger Tree Locator…

Se selecciona la opción 2

Criteria›Phase Clearances…

Se seleccionan las condiciones extremas: viento máximo con Creep y temperatura mínima Inicial RS

Criteria›Insulator Swing & Uplift…

Para el balanceo de aisladores, es importante tener en cuenta la coordinación de aislamiento en dos escenarios Distancia de seguridad para Sobretension a frecuencia industrial con Vmax y distancia de seguridad para sobretensión atmosférica con Vprom

Criteria›Default Wire Temperature and Condition, Section Sort Order…

Se definen los criterios de temperatura y condición de cables por defecto, usados por PLS-CADD para el tendido (stringing) de los cantones. Se coloca la temperatura promedio, condición creep RS, EDS; Initial RS y Wind From Left y se selecciona "Sort by start structure number then..." (opcion 2)

Glosario

ClearanceDistancia libre, distancia de seguridad o distancia de despeje
CreepDeformación plástica del conductor
Every Day Stress (EDS)Tension diaria (Tensión inicial que se da al conductor para que tenga una flecha adecuada)
EDS InicialEDS antes de desarrollarse Creep
EDS FinalEDS luego de desarrollarse Creep
CHSCarga horizontal de servicio (Tensión horizontal máxima permitida al conductor durante su operación normal considerando el comportamiento a largo plazo, como la relajación (creep) del material)
Ruling Span (RS)Vano Regulador o vano de control
SagFlecha del conductor
Sag Tensión ReportTablas de flechado (o de tensado)
SpanVano o distancia entre dos estructuras

Extensiones de archivos

.xyzArchivo principal de PLSCADD, contiene todos los puntos xyz importados
.FEAArchivo de códigos carácteristicos
.wirArchivo de cable
.stkArchivo de estructura
.criArchivo de criterios
.LCAArchivo de casos de carga
.conArchivo de restricciones (limitaciones de distribución de estructuras)
.donArchivo con la información de distribución, tendido y flechado para una línea
.bakCopia de respaldo de un proyecto
.brkArchivo de puntos de ruptura
.numArchivo de alineamientos
.ppsArchivos maestros de los parámetros de dibujo (layouts, etc.)
.STRIncluye todos los archivos de estructuras que se han usado en el proyecto estructuras disponibles
.tinContiene información acerca del modelo triangulado (TIN) del terreno
.wndSalva el estado de las ventanas (vistas abiertas, escala, rotación y traslación del modelo en la ventana)
.prtArchivos de lista de partes y conjuntos
